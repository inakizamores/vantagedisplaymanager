# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**The short version:** be respectful, assume good faith, keep discussions technical, and
remember that display bugs are usually the hardware's fault before they're anyone else's.

Unacceptable behavior can be reported privately to the maintainer via
[GitHub](https://github.com/inakizamores). Reports are handled confidentially.
